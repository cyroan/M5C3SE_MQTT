M5C3SE_MQTT 使用手冊

本系統專為 M5Stack CoreS3 設計，提供強大的 MQTT 數據監控、雙網路切換、4x3 診斷圖示、物理量數值及信號品質 (DB/RSSI/LSNR) 監控界面。

1. 啟動與自動運行 (Auto-Run)

開機後進入引導界面。若 30 秒 內無觸碰操作，系統將自動啟動：

  • 連線記憶與無 SD 卡相容：若無 SD 卡，系統自動預設運行網路為 LAN (DHCP)。連線成功後，自動將 Gateway IP 設定為 MQTT Broker 的伺服器 IP，連接埠預設為 1883。
  • 連線診斷：在 Connecting... 畫面會以黃色字體顯示當前的 SSID、密碼及連線模式，便於排查設定問題。
  • 防衝突機制：若已手動進入 UPDATE 模式，自動運行計時器將自動禁用，確保更新不被中斷。
  • 跨頁防穿透守衛 (Touch Release Guard)：進入主畫面或其他頁面時啟動保護，手指完全放開前不會誤觸發任何按鈕。

2. MQTT 監控與四大模式切換 (Display Modes & UI Interaction)

  • 點擊 RUN 進入網路選擇界面（支援 WiFi / LAN DHCP / LAN STATIC）。
  • 動態字體加大：當接收到的 Topic 符合 PW/#、Advantech/# 或包含 RSSI（不限大小寫，含新舊歷史訊息）時，監控內文字體自動加大一號至 TextSize 3 方便閱讀。
  • 在監控畫面點擊頂部標題或螢幕，即可彈出 橘色模式選擇選單（支援 5 秒自動返回與 3 秒誤觸保護）：
    • MONITOR (MQTT)：MQTT 文本消息監控與歷史紀錄。
    • DIAGNOSTIC (ICONS)：4x3 圖示矩陣診斷界面。
    • VALUES (DATA)：物理量數據與故障列表。
    • DB / RSSI (SIGNAL)：雙大卡片 RSSI 與 LSNR 信號品質儀表板。

3. 診斷圖示模式 (DIAGNOSTIC Mode)

提供 4x3 圖示陣列，直觀顯示設備故障狀態（Display Position 排列）：

列 \ 欄Col 1Col 2Col 3Col 4
Row 16. Bolts looseness10. Bearing looseness7. Housing looseness9. Bearing sleeve
Row 28. Bearing damage5. Structural looseness2. Misalignment1. Unbalance
Row 34. Oil Whirl11. Gearbox damage3. Vortex problem12. Rotor eccentricity
  • 故障觸發：對應圖示恢復全亮並加上紅色邊框。支持 Address 7（水漩 + 油漩）雙重同時亮框。
  • 正常狀態：未觸發之圖示以暗藍色顯示；若無任何異常，畫面中央顯示大型綠字 ALL PASS。

4. 數值物理量模式 (VALUES Mode)

  • 上半部物理量：即時顯示 X/Y/Z 速度 (mm/s)、溫度 (°C) 及轉速 (RPM)。
  • 警報連動：若觸發 AlarmX/Y/Z 警報，速度數值將以紅色字體高亮提醒。
  • 轉速隱藏切換：點擊 Speed 行可切換顯示/隱藏 `[Hidden]`，設定將保存於 SD 卡 /gui_pref.txt。
  • 下半部診斷文字：列出當前異常項目。當項目過多時，可透過右側藍色箭頭 (^/v) 進行觸控捲動查看。無異常時顯示 Status Normal。

5. DB / RSSI 信號品質模式 (DB / RSSI Mode)

專門用於 LoRa 及無線設備連線品質監控：

  • 自動訂閱：背景自動訂閱 uplink/# 與 Advantech/+/data。
  • 設備資訊分行顯示：
    • 第一行：SN: 設備序號（由主題或 JSON 自動提取）。
    • 第二行：Time: 封包接收時間戳。
  • 雙大卡片儀表板：
    • 左卡片 RSSI (dB)：大字體呈現信號強度，附帶動態色彩水平量表。
      • > -80 dB：綠色 (良好)
      • -80 ~ -100 dB：黃色 (警告/中等區間)
      • < -100 dB：紅色 (微弱警戒)
    • 右卡片 LSNR (dB)：大字體呈現信噪比與動態量表。
  • 獨立過濾保護：uplink/# 訊息僅在此模式解析顯示，不會洗版或干擾原有的 MONITOR 訊息紀錄。

6. 歷史紀錄回顧 (Review)

進入監控界面後，系統會自動保留最近 10 筆 接收到的消息：

  • 點擊右下角 UP：查看上一筆歷史數據。
  • 點擊右下角 DN：查看較新的數據。翻至最新一筆時會自動切換回實時監控。
  • 畫面頂部會顯示 [1] ~ [10] 提示當前回顧索引。
  • 防空存機制：無 SD 卡時收到訊息自動跳過檔案儲存操作（`/RECEIVR.TXT`）。

7. 設定功能

A. 系統校時 (SET RTC)

點擊主畫面 SET RTC：

  • 直接點選欄位：畫面上方提供 5 個獨立時間卡片（年 / 月 / 日 / 時 / 分），直接輕點任一卡片即可立即選取並亮黃框。
  • 加大按鍵與智慧連發：使用大尺寸 + / - 調整數值（輕按步進 1，長按 500ms 後啟動 250ms 平緩連發）。
  • 防穿透儲存：點擊下方綠色 SAVE 寫入硬件 RTC 並返回主畫面，配合防穿透守衛，手指未放開前絕不誤觸主畫面按鈕。

B. 9 宮格輸入法 (適用於密碼、靜態 IP、MQTT 設定)

全面重構為直覺的雙層複合鍵盤：

  • 頂部資訊與控制：左側顯示當前編輯欄位與文字游標，右側配置紅色 BS (退格鍵) 與綠色 OK (確認鍵)。
  • 中間 3x3 九宮格：提供 9 顆大尺寸按鈕 (abc 1 ~ yz 9 0)，點擊展開底部候選字。
  • 底部候選列 / 快捷功能：
    • 點擊九宮格後：水平展開 4 個字元候選按鈕與紅色 X 取消鍵。
    • 未展開狀態：提供 a/A (大小寫切換)、SYM (符號 .:/@-)、SPC (空格) 與 CLR (全部清除)。

8. 固件更新 (UPDATE)

點擊 UPDATE。系統將強制開啟 WiFi 並連線至 GitHub 檢查最新固件。

注意：進入此模式後會自動鎖定背景計時器，避免與 30 秒自動運行衝突導致更新失敗。
